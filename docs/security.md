# STRIDE threat model

Trust boundaries: client/ingress, gateway/backend, gateway/Redis, gateway/control, control/PostgreSQL, administrator/IdP
and telemetry export. Local Compose is loopback HTTP for development. Production must supply trusted TLS ingress,
private egress, Redis ACL/TLS, PostgreSQL TLS/backups, secret rotation and workload identity. Forwarded headers never
establish identity; this implementation strips them and uses the actual peer IP. An ingress deployment needing original
client IP must explicitly implement and test its trusted-hop contract before enabling it.

Test references below name executable coverage; [verification](verification.md) records which checks ran. A unit check,
one raw-socket framing probe or a DOM test does not establish exhaustive parser/browser security.

| Threat / STRIDE                  | Mechanism and impact                               | Prevention                                                                                                       | Detection / automated check                                   | Residual risk                                                                                                                   |
|----------------------------------|----------------------------------------------------|------------------------------------------------------------------------------------------------------------------|---------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------|
| Authentication bypass / S        | Missing/invalid credential reaches backend         | Default protected admission, fixed authenticators                                                                | JWT tests; acceptance.security; 401 metrics                   | New routes/filters require security review                                                                                      |
| Authorization bypass / E         | Valid caller invokes forbidden API                 | Tenant + scope + role AND; backend category/ownership checks                                                     | role/tenant HTTP suite; BackendIdentityTest                   | No external membership/PDP lookup                                                                                               |
| Key theft / S,I                  | Stolen secret impersonates application             | 256-bit generation, one-time secret, verifier storage, TLS                                                       | issuance/revocation HTTP flow; invalid-attempt throttle       | Application credential theft still requires revocation                                                                          |
| JWT signature manipulation / T   | Changed payload/signature or algorithm             | Nimbus RS256 allowlist, trusted keys                                                                             | JwtSecurityTest + altered-signature HTTP                      | Signing-key compromise                                                                                                          |
| Issuer/audience confusion / S    | Token from another security boundary               | Exact issuer and separate data/admin audiences                                                                   | wrong issuer/audience tests; admin token HTTP denial          | New issuer mapping must be reviewed                                                                                             |
| Open proxy / E                   | Caller chooses arbitrary destination               | Only validated immutable routes, exact allowed origins                                                           | route validator + HTTP SSRF attempts                          | Operator allowlist mistakes                                                                                                     |
| SSRF / T,E                       | Metadata, loopback, userinfo URL target            | Reject non-allowlisted origins; egress network policy                                                            | controlled HTTP metadata/localhost target tests               | DNS rebinding/operator DNS compromise needs network enforcement                                                                 |
| Route poisoning / T              | Malicious/partial configuration changes traffic    | Admin RBAC, revision CAS, whole-snapshot validation, immutable history                                           | race/invalid publish/rollback HTTP checks                     | Privileged operator or database compromise                                                                                      |
| Identity spoofing / S            | Forged X-User/X-Tenant/X-Gateway headers           | Strip and sign new short-lived identity; backend verifies                                                        | forged-header HTTP; signed-backend identity tests             | Short assertion replay window; rotate signing keys                                                                              |
| Forwarded spoofing / S           | Fake XFF evades IP protections                     | Strip forwarded metadata, actual peer IP limiter                                                                 | forged XFF HTTP; invalid-attempt limiter                      | All callers behind an ingress share peer-IP budget until trusted-hop support is deployed                                        |
| Host injection / T               | Host changes route/link target                     | Explicit host predicates; no external URL construction                                                           | host/method routing HTTP                                      | Ingress must restrict public hostnames                                                                                          |
| Request smuggling / T            | CL/TE/parser disagreement                          | Maintained Netty parser, strict CL/TE and chunked-write policy                                                   | protocol unit tests + raw socket HTTP probe                   | Differential parser fuzzing across actual ingress chain remains required                                                        |
| Response splitting / T           | Header CRLF injection                              | No arbitrary header scripts, allowlisted literal predicates, framework header validation                         | route/header validation tests                                 | New transformations need adversarial tests                                                                                      |
| Path normalization / E           | Semicolon/double slash changes authorization path  | Reject ambiguous forms before routing                                                                            | live path tests                                               | Actual ingress normalization must match                                                                                         |
| Encoded traversal / E            | Encoded dot/slash bypasses route                   | Restricted version paths and percent-encoding denial                                                             | route validator + encoded traversal HTTP                      | Restricted URL contract excludes some legitimate encoded resources                                                              |
| CORS / I                         | Unintended browser origin reads data               | Explicit origin allowlist, no credential sharing                                                                 | allowed/denied preflight HTTP                                 | Operator origin mistakes; CORS does not authorize APIs                                                                          |
| CSRF / E                         | Ambient browser credential performs admin action   | Stateless bearer API, no cookie authentication                                                                   | unauthorized admin HTTP; portal test                          | XSS can steal manually entered token; use production OIDC PKCE                                                                  |
| TLS / I,T                        | Interception/weak trust                            | TLS ingress manifest/secret references; production mTLS design                                                   | Manifest dry-run only                                         | Local HTTP demo is not transport security evidence                                                                              |
| WebSocket bypass / E             | Upgrade bypasses policy or retains stale authority | Same handshake policy, signed backend assertion, cap/lifetime                                                    | real Gateway+backend echo/cap tests                           | Application message authorization and deployment reconnect behavior remain application-owned                                    |
| DoS / D                          | Floods, slow calls, pool exhaustion                | Distributed buckets, quotas, 1MiB body/16KiB header bounds, deadlines, immediate concurrency, bounded pool/queue | burst/deadline/bulkhead HTTP; pool context check              | Target-scale connection/TLS/slow-client tests and edge controls required                                                        |
| Quota bypass / T                 | Racing pods overspend or reset periods             | Lua atomic check/increment, Redis TIME and monotonic period clamp, same-slot keys                                | real two-client Redis concurrency, rollover; two-Gateway HTTP | Redis acknowledged-write loss can undo usage                                                                                    |
| Redis failure exploitation / D,E | Outage bypasses limiter or key verifier            | Bounded fail-closed admission, registry reconciliation                                                           | stop/start Redis HTTP; revoke/reconcile race                  | Availability loss; async failover consistency is weaker than a durable ledger                                                   |
| Admin escalation / E,R           | Consumer/tenant actor changes platform             | Separate audience/scopes; revision guards; actor audit                                                           | unauthorized admin HTTP, audit/CRUD portal checks             | No delegated tenant admin or approval workflow; external tamper-evident audit required                                          |
| Sensitive logs / I               | Credentials/query/payload enters telemetry         | No wiretap/body logging; sanitized diagnostic frames; collector attribute deletion                               | live credential/query canaries; dependency scan               | Logging configuration and new instrumentation need continuous review                                                            |
| Upstream impersonation / S       | Attacker replaces service/DNS endpoint             | Exact origins, private network policies, signed identity to backend                                              | backend signature tests; manifest validation                  | Backend certificate/workload validation requires production TLS/mTLS; signed caller identity alone does not authenticate server |

Telemetry labels use bounded route/status categories, not consumer IDs, raw keys or arbitrary URLs. Route cardinality
still grows with configured APIs; capacity testing must include that dimension. Dependency/SBOM scans and image scans
are separate gates. Keep generated secrets out of Git and source build context, restrict management ports and database
identities, and test restore drills before external adoption.
