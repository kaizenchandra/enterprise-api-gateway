Enterprise Gateway

Control plane administration

Session

Use an access token for audience gateway-admin. Tokens and issued key secrets stay in this tab; they are never saved in browser storage.

Resources and drafts

Changes activate only after publishing. Routes may reference rateLimitPolicyId, quotaPolicyId and planId; named policies are resolved and validated together at publication.

Consumer keys

Use the consumer ID for issuance and inspection. Use the key ID for rotation or revocation. Issuance/rotation use JSON scopes, roles and days.

Usage and quota corrections

Correction JSON requires dailyUsed, monthlyUsed, idempotencyKey and reason. Use the usage revision in If-Match; zero values reset counters. Every correction is audited.

Publish and recover

Review gateway versions and lastSeen in the Gateways resource. A change is eventually reconciled by every healthy instance; existing requests retain their captured policy.
